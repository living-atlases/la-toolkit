- Source para el branding, puede ser un directorio o una dirección. En este último caso usará git para descargar y construir el branding vía git, o en su defecto intentará hacer lo mismo usando el directorio local indicado (tipicamente ../short-project-name-branding), donde resida tu branding.
branding_source=por defecto ../<project-short-name>-branding/ o una dirección de git.

Esto solo es útil para demos en las que se usa un subdominio del dominio de pruebas l-a.site. Más info en: https://github.com/AtlasOfLivingAustralia/documentation/wiki/Before-Start-Your-LA-Installation

- docker_mail_development_url=mailhog.l-a.site (textfield)
